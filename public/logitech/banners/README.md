## Exportación recomendada

- Desktop: MP4 H.264, 1920 x 1080 (16:9).
- Móvil: MP4 H.264, 1080 x 1350 o 1080 x 1440.
- Sin pista de audio; la reproducción automática siempre será silenciosa.
- 8 a 15 segundos por video, preferiblemente con inicio y final compatibles.
- Poster WebP con el mismo encuadre del primer fotograma.
- Objetivo de peso: menos de 5 MB desktop y menos de 3 MB móvil.
- Evitar texto importante pegado a los bordes.

No reemplaces ni borres este README al subir los archivos.
